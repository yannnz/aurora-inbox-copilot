    Known limitations

    Scope decisions for this prototype — not a full product claim.

    1. Handles only Ren’s morning email triage for fictional Aurora Materials (company + university). No login, CRM, dashboards, or live mailbox sync.
    2. English synthetic emails in this project’s exact CSV/record shape. Real Gmail/Outlook threads, Chinese WeChat, or messy free-text inboxes are out of scope.
    3. The agent triages one email at a time, with same-sender morning emails included only as context for duplicate/related detection. Run All is sequential demos, not parallel production throughput.
    4. Urgency uses a frozen scenario clock (11 May 2026 morning), not the viewer’s real date. Calendar/flight rows are synthetic context only — nothing is booked or sent.
    5. Needs a browser API key (and the local Kimi proxy when using Moonshot). Drafts stay suggestions until a human clicks Approve, Edit, or Escalate — the prototype never auto-sends.
