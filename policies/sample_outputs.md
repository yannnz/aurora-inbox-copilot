# Sample Output (format example only)

This shows the SHAPE of a well-formed agent output card. It is a format guide only — it is NOT an answer to any real email in the inbox. The agent must fill each field from the actual case it is given.

## Example card

- **Priority:** P1
- **Domain:** Company
- **Category:** Supplier
- **From:** [sender name] ([org]) - [relationship note]
- **Summary:** [one or two sentences summarizing the email]
- **Urgency reason:** [why this tier - name the deadline, stakes, or lack thereof]
- **Recommended route:** [Ren, or Delegate -> [employee name] ([role])] [continuity note if any]
- **Inbox relationship:** [none, or duplicate of EM-XX, or related to EM-XX — same sender alone is not enough]
- **Draft reply:** [a suggested reply, OR "none - escalated", OR "none - duplicate"]
- **Prepared action:** [calendar event / flight options / none]
- **Flag:** [Needs approval / REFUSED-ESCALATE]
- **Escalation:** [none, or the trigger name + reason]
- **Confidence:** [High / Medium / Low]
- **Citations:** [policy sections and record IDs used, e.g. priority_rules.md Section 2; senders.csv S-03]
